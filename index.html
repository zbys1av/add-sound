Завантажити відео

Як працює SoundLayer

  1. Монтаж у No Pause Allowed. Збережіть готове MP4 та відкрийте SoundLayer у браузері на тому ж пристрої або перенесіть файл на інший.
  2. Додайте готове відео. Воно залишається у браузері: SoundLayer не вирізає пауз і не змінює зображення.
  3. Додайте звуки. Оберіть атмосферу чи завантажте аудіо. Можна поєднувати кілька доріжок.
  4. Налаштуйте звук. Змініть час початку, тривалість, гучність, плавну появу/згасання. Кнопка автоматичного переходу зручно розподілить композиції.
  5. Експортуйте. У підтримуваних браузерах швидкий режим копіює закодовані відеокадри без перекодування і кодує лише звук. Якщо швидкий режим недоступний, ви самі вирішуєте, чи запускати повільніший FFmpeg.wasm із -c:v copy.

Бібліотека використовує польові записи з Wikimedia Commons (суспільне надбання / CC0) з резервними локальними семплами. Для завантаження польових записів потрібен інтернет. Для першого експорту потрібен інтернет для завантаження браузерного рушія. FFmpeg.wasm (близько 32 МБ) завантажується лише для запасного режиму. Для найкращої сумісності відкрийте застосунок із GitHub Pages, а не напряму через file://. Великі відео можуть перевищувати доступну пам’ять браузера.
